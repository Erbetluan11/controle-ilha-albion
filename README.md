# Controle da Ilha - Albion Online

Painel simples para registrar plantios e colheitas da ilha e consultar precos de mercado.

- Registro de plantios, colheitas, taxas e saldo
- Graficos de resultado
- Consulta de precos pela API do Albion Online Data Project
- Dados salvos no navegador, com exportacao e importacao em JSON

Site: https://erbetluan11.github.io/controle-ilha-albion/
